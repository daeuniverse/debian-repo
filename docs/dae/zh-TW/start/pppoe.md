# PPPoE 介面
若要代理 PPPoE 介面，請將 wan/lan_interface 設為 pppd 產生的介面（即 ppp0 / pppoe-wan），而非實體介面。
若僅將 PPPoE 介面用於 WAN，只需將 wan_interface 設為 "auto"。
