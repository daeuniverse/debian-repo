# PPPoE 接口
如果要代理 PPPoE 接口，请将 wan/lan_interface 设置为 pppd 生成的接口（即 ppp0 / pppoe-wan），而不是物理接口。
如果仅将 PPPoE 接口用于 WAN，只需将 wan_interface 设为 "auto"。
